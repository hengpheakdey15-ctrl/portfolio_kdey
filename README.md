# Heng Pheakdey Portfolio

## Files
- `index.html` — main website
- `style.css` — design and responsive layout
- `script.js` — menu, dark/light mode, animations
- `assets/profile.png` — profile photo

## Before publishing
Open `index.html` and replace:
- `YOUR_EMAIL@example.com`
- `YOUR_USERNAME` in GitHub
- `YOUR_USERNAME` in LinkedIn

## GitHub Pages
1. Upload all files while keeping the same folder structure.
2. Open repository **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Choose `main` and `/ (root)`.
5. Click **Save**.
6. Wait a few minutes and open the generated GitHub Pages URL.
