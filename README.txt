# Heng Pheakdey — Personal Portfolio

A responsive personal portfolio website for an IT student / junior software developer.

## Files
- `index.html` — main website
- `style.css` — design and responsive styling
- `script.js` — menu, dark/light mode, scroll animations
- `assets/profile.png` — supplied profile image

## Run
Open `index.html` in a browser.

## Customize before publishing
1. Replace `your.email@example.com` with your real email.
2. Replace the GitHub and LinkedIn placeholder links/usernames.
3. Add real GitHub links/screenshots to the project cards if available.
4. Update project descriptions to match your final project details.
